---
title: Limitations
---

WallPanel Reborn renders pages using the device's Android System WebView. WebView isn't the same as the Chrome app, so a page that looks fine in Chrome may not render correctly in WallPanel Reborn.

How well pages render depends on your device's WebView version. Old devices that no longer receive updates can be stuck on a very old WebView (for example, Chromium 52 on some Android 7 photo frames), and modern dashboards may fail to load or display incorrectly on them. If your device can update **Android System WebView** from the Play Store, do that first. A future release of WallPanel Reborn will be able to load a newer WebView engine on these devices.

Setting WallPanel Reborn as the default Home app means it always opens as your home screen. Undoing this can be awkward without uninstalling the app, so only do it if you want to use the device as a dedicated kiosk.
